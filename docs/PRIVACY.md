# 隐私与数据处理说明

（与小程序「设置 → 隐私与数据处理」中的文字一致；正式上线前需按实际数据处理方式重写并经法务/合规确认。）

## 1. 收集什么

| 数据 | 何时收集 | 是否必需 |
|---|---|---|
| 商品截图/照片 | 你主动选择上传 | 必需（否则无法分析） |
| 手填字段（成分、标准号、尺码表等） | 你主动填写 | 可选 |
| 身材与偏好（身高体重围度、宽松偏好、场景） | 你主动填写 | 可选 |
| 分析记录与收藏 | 自动（本地） | 可选（可删除） |
| 反馈文本 | 你主动填写 | 可选 |

不收集：通讯录、位置、手机号、微信昵称头像、设备标识，也不做行为埋点。

## 2. 存在哪里

- **本地模式（默认）**：全部在手机小程序的 `storage` 里，**不上传任何服务器**。
- **后端模式**：图片与你填写的字段会发送到你自己配置的服务端地址（`设置 → 后端地址`）。
  服务端是否再调用第三方视觉模型，取决于该服务端的 `.env` 配置，你有权知道并选择。

小程序端**没有任何第三方 SDK、没有统计、没有广告**。

## 3. 服务端会存什么

`server/server.js` 只落盘：
- 分析 id、时间、模式、是否演示；
- 图片的 **id 与类型**（**不存图片字节**）；
- 结构化字段与报告。

**不存**：身高体重等个人资料（只在单次请求内使用）、IP、微信身份。

服务端日志只记录错误摘要，不打印密钥、不打印图片内容、不打印完整请求体。

## 4. 密钥与安全

- 视觉模型密钥只存在于服务端 `.env`，**绝不进小程序包**；
- `scripts/self-check.js` 会扫描小程序包里的疑似密钥模式并直接失败；
- 上传做三重校验：数量（≤9）、大小（≤5MB）、扩展名（jpg/jpeg/png/webp）；
- 服务端有请求体上限、每 IP 限流、可选 AppID 白名单；
- 不得把本服务直接暴露在公网：它没有账号与权限体系，只是开发/自用后端。

## 5. 你的控制权

- 单条记录删除：历史页 → 删除；
- 全部记录：设置 → 清空记录 / 历史页 → 清空全部；
- 身材资料：设置或身材页 → 删除；
- 全部数据：设置 → 删除我的全部数据（清空 storage）；
- 卸载小程序或清除小程序数据即删除本机一切数据。

## 6. 不做的事

- 不把你的图片用于模型训练；
- 不在未告知的情况下转交第三方（后端模式下的模型调用在 README 与设置页说明）；
- 不做跨设备同步，也不假装有云端备份。

## 7. 能力边界（会被误读的部分，这里再说一次）

- 分析结果是**信息整理与规则提示**，不是检测报告；
- 不判断商品是否合格、是否符合标准、是否为正品；
- 标准状态来自官方公开平台的实时抓取，带核验时间；未抓到的标"待核验"；
- 面料知识是通用特性，不是这件衣服的实测表现。

## 8. 上线前必须补的

- 正式《隐私政策》与《用户协议》（需与实际数据流一致）；
- 小程序类目与"收集个人信息"声明（若接入登录/上传，需在后台配置）；
- 若接入第三方模型：在隐私政策中列明接收方、处理目的、数据保留策略；
- 若落地数据库：补充访问控制、加密存储、留存期限与删除审计。
